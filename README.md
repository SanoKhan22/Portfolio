## 🚀 Getting Started

### Prerequisites

- Node.js 18.18.0 or higher (Node.js 20 recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/SanoKhan22/Portfolio.git

# Navigate to project directory
cd Portfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in your browser.

## 📦 Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion

## 📱 Responsive Design

All animations are optimized for different devices:
- **Desktop:** Full animation suite with 60fps target
- **Mobile:** Simplified, faster animations (30% faster)
- **Reduced Motion:** Respects user preferences, disables animations
